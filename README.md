# Analiza Przestrzenna i Demograficzna Globalnego IQ

Projekt analityczno-badawczy zrealizowany w języku **R**, badający zależność między średnim ilorazem inteligencji (IQ) a wskaźnikami rozwoju społecznego (HDI), edukacji i gospodarki na świecie.

## 🚀 Live Demo
Możesz zobaczyć interaktywny raport oraz mapę online pod adresem:
👉 [Link do Live Demo](https://radoslawg123.github.io/Global_IQ_Spatial_Analysis/)

## 🛠️ Wykorzystane Technologie
* **R** (`tidyverse`, `dplyr`) – przetwarzanie i czyszczenie danych.
* **Quarto** – generowanie nowoczesnego raportu reprodukowalnego.
* **Leaflet** – interaktywna mapa z wizualizacją danych demograficznych.
* **Plotly** & **ggplot2** – zaawansowane wykresy 2D i 3D.
* **DT** – interaktywne tabele danych.

## 📂 Struktura Projektu
- `main.qmd` – główny kod źródłowy raportu Quarto.
- `index.html` – skompilowana wersja strony internetowej raportu.
- `dane/` – zanonimizowane pliki źródłowe CSV.
